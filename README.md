# AI生成的职教高考学生端 React 原型

这是一个Codex生成的基于 Vite、React 和 Tailwind CSS 的前端交互原型，用于向设计和业务同学展示学生端页面流程。

## 在线预览

推送到 GitHub 后，仓库会通过 GitHub Actions 自动构建并发布到 GitHub Pages。

首次发布后，在仓库的 `Settings` -> `Pages` 中确认 Source 使用 `GitHub Actions`。发布成功后，页面地址会显示在 Actions 的部署记录里。

## 本地运行

```bash
cd student-prototype-react
npm install
npm run dev
```

## 构建

```bash
cd student-prototype-react
npm run build
```
