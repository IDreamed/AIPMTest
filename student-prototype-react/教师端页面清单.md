# 教师端页面清单

本清单将 Axure 学校侧教学页面迁移为教师端前台。由于后台班级权限现阶段无法调整，一期同时迁移教师开始教学前必需的建班和学生分班能力；学校组织、审核和权限配置仍留在学校管理后台。

| 教师端页面 | 路由 | Axure 来源 | 已对齐的关键字段与动作 |
| --- | --- | --- | --- |
| 教学资源 | `#/teacher/resources` | 资源库查看 | 科目/专业→资源库→四级知识点级联筛选、资源类型、名称；素材名称、类型、知识点路径、更新时间、预览 |
| 题库资源 | `#/teacher/question-bank` | 题库查看 | 科目/专业→资源库→四级知识点级联筛选、题型、难度、名称；题目 ID、题干、题型、知识点路径、更新时间、预览 |
| 组课管理 | `#/teacher/course-builder` | 课程管理、新建课程、课时、课件、课程试卷 | 课程只绑定科目/专业；课程名称、封面、简介、目录、课时、课件、课程试卷 |
| 我的课程 | `#/teacher/courses` | 课程管理 | 科目/专业、上架状态、课程名称；课程来源、更新时间及本校课程维护操作 |
| 试卷管理 | `#/teacher/papers` | 学校试卷管理、固定卷、随机卷 | 试卷只绑定科目/专业；上架状态、试卷分类、名称；来源、题量、总分及本校试卷维护操作 |
| 我的班级 | `#/teacher/classes` | 班级教务管理 | 新建班级；进入学生管理、派课、作业、学情和答疑 |
| 班级派课 | `#/teacher/assign-course` | 派课 | 选择班级、选择课程、派发、取消派课 |
| 班级作业 | `#/teacher/assignments` | 班级作业 | 作业名称、状态；绑定试卷、满分、及格分、开始结束时间、编辑、批阅、统计、删除 |
| 新建/编辑班级作业 | `#/teacher/assignment-edit` | 新建/编辑班级作业 | 当前班级、作业名称、选择专业、关联该专业下的试卷、开始时间、结束时间 |
| 作业批阅 | `#/teacher/grading` | 阅卷_1 | 选择学生、主观题得分、评语、保存批阅 |
| 作业统计 | `#/teacher/assignment-stats` | 班级作业统计 | 提交、缺交、成绩、批阅状态 |
| 学生管理 | `#/teacher/students` | 学生管理、分班、学生详情、学习详情 | 添加学生、单人调整班级、批量分班；按班级和关键词查看课程进度、作业、答疑、学习记录 |
| 学生详情 | `#/teacher/student-detail` | 学生详情、学习详情 | 基础信息、在学课程、课时学习记录、作业结果 |
| 答疑管理 | `#/teacher/qa` | 答疑 | 学生姓名、学生手机号、回复状态；回复、补充、关闭 |

## 不迁入教师端的功能

- 学生审核/停用、跨校转移、班级冻结/解散、教师角色授权和学校权限：学校管理后台。
- 平台资源、题目审核、资源审核、分类体系和平台联考：平台管理后台。
- 考试专用试卷与平台联考配置：平台管理后台。
