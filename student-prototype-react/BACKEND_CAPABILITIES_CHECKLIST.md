# 学生端原型后台规则补充文档

> 用途：这里只记录会影响学生端前端原型的信息。  
> 已确定规则不用再补；请只补充「待补充问题」中确实需要后台确认的部分。

## 一、已确定规则

### 1. 用户身份与权限

- 学生端原型身份分为：游客、注册用户、班级学生。
- 游客可浏览公开内容，但不能使用需要学习权限的功能。
- 注册用户已有账号，但未加入学校班级。
- 班级学生已加入学校班级，拥有对应学习权限。

### 2. 学校 / 班级 / 学生关系

- 学生可以加入多个学校。
- 同一学校下，一个学生只能加入一个班级。
- 班级绑定专业大类。
- 班级绑定的专业大类会影响专业课试卷、学校联考等权限。
- 学生端使用“当前学校班级”下拉切换当前班级上下文。

### 3. 首页

- 首页是公开访问页，不是学习工作台。
- 顶部菜单已经承担模块入口，首页正文不重复放试卷中心、考试中心、学习中心等快捷入口。
- 首页包含平台宣传介绍、推荐课程、资讯摘要、平台资源概览。
- 首页平台介绍应是总结性、宣传性的内容，不写成业务说明文档。

### 4. 推荐课程试看

- 首页推荐课程是运营配置内容。
- 推荐课程不等同于班级课程。
- 推荐课程不展示价格。
- 推荐课程试看页默认按视频试看处理。
- 视频试看时长只对视频课时生效。
- 推荐课程试看页不处理富文本、PDF、PPT、音频课时预览。
- 推荐课程试看页不复用学习中心完整课程详情页。
- 推荐课程试看页只保留一套视频试看课时列表，不再重复展示目录。

### 5. 资讯中心

- “资讯中心”是正确名称，不是“咨询中心”。
- 资讯中心展示平台公开资讯。
- 资讯类型为固定枚举，不提供后台动态类型管理。
- 当前固定类型：
  - 政策解读
  - 考试通知
  - 平台公告
  - 备考指南
- 资讯详情当前原型使用弹窗展示。
- 考试通知只是信息发布，不承担考试参加流程。

### 6. 试卷中心

- 试卷中心展示平台独立刷题资源。
- 试卷中心不包含课程内试卷、班级测试、考试中心考试。
- 当前没有公开可作答试卷。
- 游客可浏览试卷资源概况，但不能作答。
- 注册用户可浏览试卷资源概况，但不能作答。
- 只有班级学生可以作答有权限的试卷。
- 公共课试卷包括：语文、数学、英语。
- 专业课试卷按专业大类授权。
- 专业课试卷权限由当前学校班级绑定的大类决定。
- 试卷状态为：未开始、进行中、已结束。
- 试卷刷题允许保存进度、继续刷题、查看解析、重新开始。
- 无权限用户不开放试卷作答界面。

### 7. 试卷刷题页

- 试卷刷题页只面向有权限的班级学生。
- 试卷刷题不是正式考试。
- 试卷刷题支持完成练习后系统判卷客观题。
- 完成练习后给出解析。
- 错题进入错题本。
- 试卷刷题允许保存进度和继续作答。

### 8. 考试中心

- 考试中心只包含公开考试和学校联考。
- 考试中心不包含班级测试、课程练习、试卷刷题。
- 公开考试面向注册用户开放。
- 游客可浏览公开考试概况，但不能参加。
- 注册用户可以参加公开考试。
- 班级学生可以参加公开考试。
- 学校联考按学校、班级、专业大类授权。
- 注册用户无学校班级授权，不能参加学校联考。
- 考试状态固定为：
  - 未开始
  - 进行中
  - 评审中
  - 已公示
- 学生考试状态固定为：
  - 无权限
  - 待开始
  - 可参加
  - 已交卷
  - 未参加
  - 查看成绩
- 考试中心筛选包含：考试类型、科目、专业大类、考试状态。
- 考试中心不做“我的状态”筛选。

### 9. 正式考试答题

- 正式考试必须一次完成。
- 正式考试不保存中途状态。
- 进入考试页不算参加考试。
- 交卷才算参加考试。
- 正式考试不展示自动保存。
- 正式考试不展示保存并下一题。
- 正式考试不支持继续考试。

### 10. 成绩、公示、排名

- 公示属于考试生命周期，不属于学生个人状态。
- 已公示表示考试结果已发布，考试生命周期结束。
- 排名功能由后台配置。
- 学生端只根据后台配置适配展示，不提供排名配置能力。
- rankEnabled = true 时，学生端展示成绩 + 排名相关内容。
- rankEnabled = false 时，学生端只展示成绩/结果，不展示排名榜单。
- 考试中心不展开上千人公示榜单，完整内容进入考试公示页。

### 11. 班级测试

- 班级测试属于学习中心/班级内部。
- 班级测试不属于考试中心。
- 班级测试不使用考试中心详情页。
- 班级测试不展示联考排行。
- 班级测试用于老师在班级内布置小测、阶段测、结业测、课堂练习等轻量测试。

### 12. 班级答疑

- 班级答疑是一对一留言。
- 班级答疑不做实时聊天。
- 答疑可以作为班级学习的一部分展示。

### 13. 错题本与学习记录

- 错题本是学生个人学习资产，高于班级。
- 学习记录是学生个人学习资产，高于班级。
- 错题本和学习记录可以支持按学校班级筛选，但入口不属于某个班级。

### 14. 学习中心

- 学习中心是登录后的学生工作台。
- 学习中心不是首页。
- 学习中心首页只做摘要，不承接所有完整列表。
- 学习中心首页通过“当前学校班级”下拉提供班级上下文。
- 学习中心首页不展示完整课程列表、完整试卷列表、完整考试列表、完整答疑列表、完整错题列表。
