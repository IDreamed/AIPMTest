# 一期项目交付目标

## 目标定位

一期交付目标是建设“教学管理与学生学习闭环底座”。平台不是单一学生学习端，而是同时包含教师端前台、学生端学习流程、公开访问入口和运营后台基础内容管理。

一期重点是把后端已实现、Axure 已导出的教师教学功能前端化，并和学生侧课程学习、作业、考试、练习、错题、答疑、学习记录形成闭环。

当前一期以 React 前端原型和 mock 数据为交付边界，重点验证业务结构、页面流程、权限关系和交互一致性；不要求真实接口联调，不做复杂统计看板和深度数据分析。

平台管理端始终是后端管理端，功能基本已实现；一期 React 原型不重做平台管理端。由于需求边界调整，平台管理后端和学校管理后台中的部分页面仍需要按新命名、新端侧边界和试卷/考试规则做界面调整。

## 业务闭环

- 教师侧：新建班级并分配学生，查看授权资源，组建课程，维护课时/课件/课程试卷，给班级派课，布置班级作业，批阅主观题，回复答疑，查看学生学情。
- 学生侧：申请加入学校和班级，学习课程，完成课时和课堂练习，查看资料，提交作业，参加正式考试，自主试卷练习，沉淀错题，发起答疑，查看学习记录。
- 平台侧：通过首页、资讯、推荐课程、报考指南、虚拟实训入口和运营后台支撑基础内容运营。
- 数据侧：一期保留课程进度、课时进度、答题状态等必要学习提醒；不展示依赖后台汇总计算的跨模块统计卡片。

## 功能清单

### 教师端前台

教师端来源于后端导出的教师功能原型，不按占位入口处理。前端实现应保留后端功能和字段语义，但视觉和交互按当前 React 前台设计系统统一重做，不直接照搬后台管理界面。

- 教学资源：资源库查看、题库查看、资源/题目预览，支持按专业大类、资源库、知识点、素材类型、题型、难度等条件筛选。
- 组课管理：课程列表、新建/编辑课程、课时管理、新建课时、选择试题、课件管理、课程试卷维护。
- 我的课程：查看和维护教师负责或学校授权的课程。
- 我的班级：新建和查看教师负责班级，进入学生管理、班级课程和教学动作。
- 班级派课：选择课程并派发给班级，支持取消派课；派课后课程进入学生学习中心。
- 班级作业：新建/编辑班级作业，选择作业试卷，设置开始时间和时长，查看提交、缺考、批阅状态，进入阅卷和作业统计。
- 学生管理：添加学生、单人调整班级和批量分班，并查看学生基础信息、在学课程、课时学习记录和学习进度。
- 答疑管理：按学生姓名或手机号搜索问题，查看问题，回复问题，支持多轮追问回复。

### 学生学习中心

- 学习中心左侧导航：我的课程、作业、我的答疑、学习记录。
- 我的课程展示课程状态、科目/专业、当前课时、发布人、已学课时、学习进度和学习入口。
- 课程详情包含介绍、目录、试卷、课件、答疑。
- 课时播放支持微课、慕课、音频、PDF、PPT、富文本。
- 音视频课时展示学习进度、已学习时间和课时练习入口。
- 课堂练习弹窗支持作答、答案反馈和题目解析。
- 课程资料预览页承接课件查看。
- 学习记录记录视频和音频课时学习情况。
- 课程进度统计作为学生必要提醒保留。

### 作业、考试与练习

- 作业作为教师布置给班级的非正式测评任务，归入学习中心。
- 作业支持列表、安排页、答题页和解析页。
- 考试中心展示当前考试和考试记录。
- 当前考试支持详情查看、正式答题和交卷确认。
- 考试记录支持成绩、解析和排行入口。
- 考试排行包含考生排行和学校排行。
- 试卷练习归入考试中心，支持科目筛选、分页、继续练习、查看解析和重新开始。
- 错题本汇总课程、试卷和考试错题，支持筛选、搜索、解析、练习、移除和批量移除。
- 试卷练习、考试、作业复用统一题目结构：单选、多选、判断、填空、简答、综合题。

### 答疑闭环

- 学生可从课程详情和课时播放页发起提问。
- 我的答疑展示个人答疑列表和分页。
- 答疑详情展示学生提问、老师回复、待补充说明和继续追问。
- 教师端答疑管理承接学生问题处理，形成学生提问、教师回复、学生追问的留言式闭环。
- 一期不做实时聊天。

### 公开访问、账号与运营后台

- 首页包含轮播、学习中心、考试中心、虚拟实训、报考指南、推荐课程和资讯摘要。
- 资讯中心支持分类浏览和详情弹窗。
- 推荐课程支持试看页，包含视频试看、介绍、试卷、课件。
- 注册表单字段顺序：申请的学校、目标专业、手机号、验证码、密码、确认密码。
- 个人中心展示基本信息、所属学校、目标专业、审核状态和账户安全。
- 学习中心、考试中心、试卷练习、错题本、虚拟实训按学生身份拦截。
- 运营后台一期交付资讯管理和首页推荐课程管理。
- 报考指南和虚拟实训一期作为基础入口和占位页面交付。

## 验收场景

- 教师登录教师端，可新建班级、添加和分配学生，并进入教学资源、组课管理、班级派课、班级作业、学生管理和答疑管理。
- 教师可基于授权资源组课并派发到班级，学生端学习中心可看到对应课程。
- 教师可布置班级作业，学生可在学习中心完成作答并查看解析。
- 教师可进入阅卷和作业统计，查看提交、缺考、批阅等状态。
- 学生可从学习中心进入课程学习，完成课时学习、课时练习、课程资料查看和课程提问。
- 学生可在考试中心参加正式考试，交卷后进入考试记录并查看成绩、解析和排行。
- 学生可通过试卷练习自主刷题，并在错题本中继续练习和查看解析。
- 我的答疑能承接课程/课时提问，教师端答疑管理能完成回复。
- 运营后台可维护首页资讯和推荐课程，支撑前台内容展示。
- 页面不展示依赖后台汇总计算的跨模块统计卡片；课程进度、课时进度、答题状态等学习提醒保留。

## 边界

- 教师端是前台业务端，不等同于运营后台或学校后台。
- 学校、用户审核、班级冻结/解散、教师角色和资源授权配置属于后台系统；教师端一期只迁移建班、添加学生和分班所需的最小能力。
- React 原型中的后台管理一期只覆盖内容运营，不覆盖完整学校、班级、用户、权限和考试发布后台；这些能力保留在既有后端管理端。
- 平台管理端保留为后端，后续只按新需求调整相关后端界面。
- 报考指南和虚拟实训一期不展开深层业务，只保留平台基础入口。
